// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace sticky [-h|--help] [--window-id <window-id>]
aerospace sticky [-h|--help] [--window-id <window-id>] [--fail-if-noop] on
aerospace sticky [-h|--help] [--window-id <window-id>] [--fail-if-noop] off

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

A sticky window is floating (tiled windows are floated when they become sticky).
Whenever another workspace becomes visible on its monitor, the sticky window moves along, keeping its position and size.
Like i3's `sticky enable`.

Stashing a window in the scratchpad makes it non-sticky.
Without an argument, the sticky state is toggled.
